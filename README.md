# RentEase – Furniture & Appliance Rental Platform

RentEase is a monthly rental website for furniture and appliances. Customers can browse items, estimate their monthly cost, and choose how many months they want to rent.

## Live Website

https://dhruv-rajani1604.github.io/rentease/

## Features

- Browse rental items with monthly prices
- Rental cost calculator that updates as you choose an item and rental length
- Responsive layout for desktop and mobile

## Built With

- HTML
- CSS
- JavaScript
- Node.js (planned for later stages)
